# API reference

Everything exported from `SoftPack`: the settings object, the size
distributions and contact laws, the packing types, the `pack` entry point, and
the softpack-1 reader and writer. In v0.1 the types, settings and IO all work
today; the `pack()` algorithms are planned and throw "not implemented yet"
until the engine lands in the next milestone.

