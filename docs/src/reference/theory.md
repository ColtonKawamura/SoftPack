# Theory pages

*Up:* [SoftPack](../index.md)

Each option page on this site says what to type, what the default is, and why.
The pages below hold the models, the derivations and the worked numbers behind those defaults.
They are still on the wiki, one page per section of the design document, and each option page links to the wiki section that matches it.
