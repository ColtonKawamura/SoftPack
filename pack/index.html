Creating a packing with pack()

Design decision source: design-references.md §0. Status: design stage (no engine code yet).

Summary

pack() with no arguments makes a 2D packing of 256 frictionless Hookean disks, a 50:50 bidisperse mixture with diameter ratio 1.4, compressed with FIRE to the pressure $P = 10^{-4}$, with rattlers removed. It starts from random, non-touching particles at packing fraction 0.25 in a periodic box and shrinks the box isotropically until the pressure reaches the target. Every setting below has a default and a reason. This page lists them all in one place: the default, what it means as an equation, the other choices, the main source, and the wiki section that explains it. Sources are cited by key and listed in full at the end; SoftPack choice marks a default with no literature source.

Units throughout: small diameter $d = 1$, contact stiffness $k = 1$, particle mass $m = 1$, so lengths are in $d$, forces in $k\,d$ (Hookean), pressures in $k\,d^{2-D}$ and times in $\tau = \sqrt{m/k}$ (Units and length unit). Symbols are defined in Notation.

The default packing in one call

Every default written out:

pack(                                                                # run the packing with every default written out
    dimension                   = 2,                                 # 2D packing of disks (use 3 for spheres)
    particles_count             = 256,                               # number of particles
    particles_size_distribution = Bidisperse(                        # two-diameter mixture
        diameter_small = 1.0,                                        # small diameter; the length unit
        diameter_ratio = 1.4,                                        # large diameter divided by small diameter
        fraction_small = 0.5                                         # number fraction of small particles (50:50)
    ),                                                               # end of Bidisperse call
    particles_diameters         = nothing,                           # draw diameters from the distribution, not an explicit list
    contact                     = Hookean(stiffness = 1.0),          # Hookean contact law, stiffness k = 1
    friction                    = nothing,                           # frictionless contacts
    mass                        = EqualMass(1.0),                    # every particle has mass 1
    target                      = Pressure(1e-4),                    # compress until the contact pressure reaches 1e-4
    boundary                    = Periodic(),                        # periodic square (2D) or cube (3D) box
    initial_state               = Dilute(packing_fraction = 0.25),   # random start at packing fraction 0.25, no particles touching
    protocol                    = IsotropicCompression(              # shrink the box in isotropic steps
        strain_step = 1e-2                                           # the box side shrinks by 1% in the first step
    ),                                                               # end of IsotropicCompression call
    convergence                 = RelativeForce(tolerance = 1e-8),   # stop when net forces are below 1e-8 of the mean contact force
    pressure_tolerance          = 1e-4,                              # relative pressure tolerance
    steps_max                   = 10^7,                              # maximum number of steps per call
    failure_action              = :warn,                             # warn and return the packing if not converged
    restart_packing             = nothing,                           # start a fresh run, no restart
    restart_file                = nothing,                           # no periodic saves during the run
    algorithm                   = FIRE(),                            # FIRE with LAMMPS FIRE 2.0 defaults, no damping, no drag
    timestep                    = CollisionTime(fraction = 1/50),    # time step is 1/50 of the collision time
    rattlers                    = ContactCount(cone_test = true),    # remove particles with too few contacts, cone test on
    seed                        = 1,                                 # random seed
    snapshots                   = nothing,                           # no snapshots recorded
    movie                       = nothing,                           # no movie rendered
)                                                                    # end of pack call

and, for files, write_packing(path, packing; rattlers_file = false, compression = nothing), which writes HDF5 (file format).

  • pack(...) — runs the packing with every default written out.
  • Each keyword is explained in the tables below: its default, meaning, other choices, main source and a link to the section with the reasons.
    • Particles, contacts, mass and target: Particles and contacts.
    • Box, start and compression: Box, start and compression.
    • Convergence, failure and restarts: Stopping, failure and restarts.
    • Algorithm and time step: Algorithm and time step.
    • Damped dynamics: Damping (damped dynamics).
    • Rattlers: Rattlers.
    • Seed and outputs: Reproducibility and outputs.
  • write_packing(path, packing; rattlers_file = false, compression = nothing) — the file call, written with its defaults (file format).
    • rattlers_file = false — write only the remaining particles (rattlers_file).
    • compression = nothing — leave the datasets uncompressed (compression).

Three ways to call pack()

pack()                                                  # every default
pack(particles_count = 2000, target = Pressure(1e-4))   # keywords
pack(params)                                            # a reusable PackParams value
  • pack() — runs with every default.
  • pack(particles_count = 2000, target = Pressure(1e-4)) — runs with the keywords you pass, and every keyword you leave out keeps its default.
  • pack(params) — runs with a reusable settings value, described on the PackParams page.
  • pack() returns a Packing, described on the Packing page.

With these defaults and Hookean contacts the damping is exactly stiffness-proportional, $\boldsymbol\Gamma = b\,\mathbf K_0$ with $b = 2\zeta/\omega_c$, so every underdamped mode decays at $\beta_\ell = b\,\omega_\ell^2/2$ (§8).

The options' own defaults: ViscousRate(normal = 0.5, tangential = 0.5), rates $r = 0.5/\tau$ with $\gamma = m_\text{eff}\,r$ [Santos2024]; RelativeVelocityDamping(rate = 0.5), $\mathbf F_{ij} = -\gamma(\mathbf v_i - \mathbf v_j)$ (the CD model of [Vagberg2014]); StokesDrag(velocity = rate), $\mathbf F = -a_v m\mathbf v$, with no default rate (§8).
