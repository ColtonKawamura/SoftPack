PackParams()

Up: pack()

A PackParams is one set of settings, built from the same keywords pack() takes. It exists so a set of settings can be built once, inspected, reused, and passed to pack:

pack(params) validates the settings and runs exactly like pack(; kwargs...) with the same keywords. The result's packing.settings is the PackParams of the run, and a restart compares its stored copy with the new keywords.

The constructor stores the settings; pack(params) validates them before the run, so an invalid setting raises an error at the call rather than after a minute of packing.

The keywords

KeywordDefaultSets
dimension2disks or spheres
particles_count256the number of particles
particles_size_distributionBidisperse()how diameters are drawn
particles_diametersnothingan explicit list of diameters
contactHookean()the normal force law
frictionnothingthe tangential model
massEqualMass()the masses
targetPressure(1e-4)the pressure to compress to
boundaryPeriodic()periodic box or walls
initial_stateDilute(0.25)where the run starts
protocolIsotropicCompression(1e-2)how the box shrinks
convergenceRelativeForce(1e-8)when a minimization is done
pressure_tolerance1e-4the width of the pressure band
steps_max10^7the step cap
failure_action:warnwhat a failed run does
restart_packingnothingcontinue from a file
restart_filenothingsave the state during the run
algorithmFIRE()the minimizer or dynamics
timestepCollisionTime()the starting step
rattlersContactCount()which particles are rattlers
seed1the random seed
snapshotsnothingstore positions at intervals
movienothingrender a movie

Example

using SoftPack

params = PackParams(
    dimension = 3,
    particles_count = 512,
    seed = 7,
)
packing = pack(params)
packing.packing_fraction
