Where is damping?

damping, drag and integrator are keywords of the algorithm, not of `pack()`

The algorithm decides whether there are dashpots at all. FIRE() takes damping and drag and defaults both to nothing. DampedDynamics() takes the same two keywords and defaults damping to ContactDamping(), and it also takes integrator, which defaults to :centered_velocity_verlet.

pack(                                              # run the packing
    algorithm = DampedDynamics(                    # damped dynamics
        damping    = ContactDamping(normal = 0.98),   # contact dashpots, normal ratio 0.98
        drag       = nothing,                         # no Stokes drag
        integrator = :centered_velocity_verlet,       # dashpot on the end-of-step velocity (default)
    )                                              # end of DampedDynamics call
)                                                  # end of pack call
  • damping: the dashpot models ContactDamping(), ViscousRate() and RelativeVelocityDamping().
  • drag: Stokes drag, StokesDrag().
  • integrator: the time stepper, :centered_velocity_verlet, :lagged_velocity_verlet or :semi_implicit_euler.
  • FIRE(): the default algorithm, with no damping and no drag.
